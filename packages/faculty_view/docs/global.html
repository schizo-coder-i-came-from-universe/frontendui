(constant) AdmissionButton

AdmissionCUDButton Component

A higher-order component that dynamically renders one of the following components based on the operation prop:

  • InsertAdmissionButton for creating a new item (operation "C")
  • UpdateAdmissionButton for updating an existing item (operation "U")
  • DeleteAdmissionButton for deleting an existing item (operation "D")

This component validates the admission prop:

  • For "C" (create), admission can be any object (no restrictions).
  • For "U" (update) and "D" (delete), admission must include an id key.

If the operation prop is invalid or required conditions for admission are not met, an ErrorHandler component is rendered with an appropriate error message.

  • Admission/Components/AdmissionCUDButton.jsx, line 70
Example
// Example Usage
const Example = () => {
  const handleDone = (data) => console.log("Operation completed:", data);

  return (
    <>
      <AdmissionCUDButton
        operation="C"
        admission={{ name: "New Item", name_en: "New Item EN" }}
        onDone={handleDone}
      >
        Insert
      </AdmissionCUDButton>

      <AdmissionCUDButton
        operation="U"
        admission={{ id: "123", name: "Updated Item", name_en: "Updated Item EN" }}
        onDone={handleDone}
      >
        Update
      </AdmissionCUDButton>

      <AdmissionCUDButton
        operation="D"
        admission={{ id: "123" }}
        onDone={handleDone}
      >
        Delete
      </AdmissionCUDButton>
    </>
  );
};
